# DEXC Tools｜Python 工具统一交互规范

本规范用于约束 `python` 目录下所有 Python 命令行脚本（`.py`）的交互风格。Python 脚本视为特殊的 CLI 脚本，交互约定与 `cli` 目录保持一致，并补充 Python 独有的环境与运行约定。

## 环境与运行约定

1. **独立虚拟环境**：`python` 目录下脚本统一运行在独立 venv（`python/.venv`）中，不污染全局环境。使用者首次使用前需在 `python` 目录下安装依赖：

   ```bash
   python3 -m venv .venv
   .venv/bin/pip install -r requirements.txt
   ```

2. **依赖清单**：依赖统一维护在 `python/requirements.txt`，多个工具可共用同一份清单。
3. **运行方式**：统一通过 `.venv/bin/python <工具名>.py` 运行，禁止依赖全局环境。

## 核心原则

1. **启动不立即执行**：先展示适用场景、功能说明、操作方式，等待用户输入后再执行。
2. **参数先收齐再执行**：需要多个参数时，逐个输入，全部收集后回显确认，再执行。
3. **路径支持拖拽输入**：允许用户拖动文件/目录到终端，脚本自动规整引号与转义。
4. **分步骤输出进度**：每个步骤结束后输出步骤结果与整体进度。
5. **结束等待确认**：执行结果汇总后，等待用户回车才结束，禁止立即退出（非交互模式下除外，见"结束确认"）。

## 启动说明模板

所有脚本启动后首先输出以下内容（分隔线使用 `=` 或 `-`，避免框线字符错位）：

```
=========================================
  <工具名称>
  版本 1.0
=========================================
[适用场景]
说明本脚本适用于什么场景。

[功能说明]
说明本脚本执行什么功能、做了什么。

[操作方式]
说明用户如何操作（选择选项、输入路径、拖拽文件等）。

[执行步骤]
1. 步骤一
2. 步骤二
3. 步骤三

[注意事项]
- 破坏性操作警告
- 权限要求
- 其它提示
=========================================
```

## 版本号

- 版本号格式：`主版本.次版本`。
- 位置：启动横幅工具名称正下方一行，形如 `版本 1.0`。
- 变更须递增版本号；版本升级遵循 `主版本`（不兼容/重大变更）与 `次版本`（功能变更/修复）约定。

## 统一信息前缀

所有提示信息统一使用以下前缀，禁止自由发挥：

| 前缀 | 含义 | 用途 |
| ---- | ---- | ---- |
| `[提示]` | 普通提示 | 引导用户操作 |
| `[进度]` | 步骤进度 | 步骤执行中/完成标记 |
| `[完成]` | 成功 | 单步成功 |
| `[失败]` | 失败 | 单步失败 |
| `[错误]` | 输入错误/异常 | 非法输入、运行异常 |
| `[结果]` | 汇总 | 脚本结束前的汇总 |
| `[输入]` | 请求输入 | 直接要求用户键入或选择的提示行（含 `input()` 所在行及菜单引导行） |
| `[结束]` | 结束提示 | "按回车键退出…"等仅用于结束脚本运行的收尾提示 |

- 凡需要用户输入或选择的场景，提示行必须以 `[输入]` 开头，禁止使用裸文本或 `[提示]`。
- "按回车键退出…"等收尾提示一律使用 `[结束]`。

## 输入约定

### 菜单选择

- 选项使用数字 `1`、`2` ... 编号。
- 提供取消选项：`q`（quit）或 `0`。
- 非法输入**循环重试**，不直接退出。
- 菜单引导行与输入行均以 `[输入]` 开头。

示例：
```
[输入] 请输入选项数字 [1 / 2 / q 取消] 然后按回车:
```

### 多参数输入

- 逐项提示，提示中标注当前进度 `(参数 1/3)`，每项均以 `[输入]` 开头。
- 全部输入完成后**回显所有参数**，用户确认后才执行。
- 允许直接回车使用默认值（如适用），提示中标注 `[回车使用默认值: xxx]`。

### 路径输入与拖拽

- 接受带引号或不带引号的路径输入。
- 接受用户直接拖拽文件/目录到终端。
- 脚本必须对输入做规整后再使用：先去除首尾引号，再还原空格转义 `\ `（macOS Terminal 拖入路径时空格被转义为 `\ `，iTerm2 可能带引号）。

```python
def clean_path(s):
    s = (s or "").strip()
    while s and s[0] in "\"'":
        s = s[1:]
    while s and s[-1] in "\"'":
        s = s[:-1]
    s = s.replace("\\ ", " ")
    return s.strip()
```

## 进度与结果输出

### 步骤进度

- 每步执行前输出 `[进度] 步骤 X/N：<步骤名> ...`
- 每步执行后输出 `[完成]` 或 `[失败]`（失败时说明原因）。
- 单步失败不中断流程时，记录失败，最后汇总中列出。

### 结果汇总

脚本结束前统一输出：

```
[结果] 执行完成。
  成功：2/3
  失败：1/3
  - <失败的步骤说明>
```

## 破坏性操作

- 删除文件、覆盖既有文件、修改系统设置、重启进程等操作前必须二次确认。
- 明确提示操作影响范围（例如"目标目录下同名文件将被覆盖"）。
- 提供 `q` 取消机会。

## 权限检查

- Python 脚本无系统级提权机制。
- 需要写入系统目录时，检查并提示用户权限，权限不足则警告或退出，并建议用户自行以合适方式处理。

## 编码与文件规范

| 文件类型 | 编码 | 换行 | 其它 |
| -------- | ---- | ---- | ---- |
| `.py` | UTF-8 无 BOM | LF | 首行 `#!/usr/bin/env python3`；Python 3 源文件默认 UTF-8 |
| `requirements.txt` | UTF-8 无 BOM | LF | 每行一个依赖，建议使用下限版本（`>=`） |

- `.py` 脚本内建议显式设置标准输入输出编码为 UTF-8，保证中文输出正确：

  ```python
  for stream in (sys.stdout, sys.stdin):
      try:
          stream.reconfigure(encoding="utf-8")
      except Exception:
          pass
  ```

## 结束确认

- **交互模式**（`sys.stdin.isatty()` 为真）：脚本所有输出完成后，以 `input("[结束] 按回车键退出...")` 收尾，再结束。
- **非交互模式**（stdin 非 TTY，如参数全由命令行指定、输出重定向到管道）：不等待输入，直接结束，避免阻塞管道。
- 取消（`q`）与错误退出同样遵循以上交互/非交互规则。
