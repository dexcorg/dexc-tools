# 大语言模型批量处理脚本

> 当前版本：`1.2`

按自定义提示词批量处理指定目录中的文件：将提示词中的 `[[CONTENT]]` 占位符替换为文件内容，调用 LLM API（OpenAI 兼容格式）处理后输出到另一目录。适用于摘要、改写、格式转换、内容审查等任意文本处理任务。

## 功能特性

- **交互式命令行**：来源/输出目录可拖放至控制台，参数收集后回显确认
- **自定义提示词**：任意自然语言描述处理方式，支持多行（含空行）输入，需包含内容占位符（`[[CONTENT]]`/`[[C]]` 等，大小写不敏感）
- **任意后缀**：可指定一个或多个目标文件后缀（如 `txt/md`），检索大小写不敏感
- **批量处理**：递归扫描来源目录，处理结果写入输出目录并镜像目录结构，输出文件名必为原始文件名（不开放自定义路径/名称），但可指定输出扩展名
- **输出扩展名**：可选配置，输出文件使用原始文件名（去后缀）+ 输出扩展名，输入统一转小写
- **编码自动探测**：支持 UTF-8（含 BOM）、UTF-16、GBK、Shift-JIS 等
- **输出清理**：自动剥离模型返回内容首尾的 markdown 代码围栏
- **自动重试**：API 调用失败时自动重试

## 环境要求

- Python 3.9+
- 可用的 LLM API（OpenAI 兼容格式，如本地 llama.cpp server）

## 安装

首次使用需安装依赖（独立 venv，不污染全局环境）：

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

依赖项：`requests`、`charset-normalizer`

## 使用方式

### 交互式运行

```bash
.venv/bin/python llm-dir-handle.py
```

启动后先展示工具说明横幅，再按提示依次输入：

1. **来源目录**（可拖放文件夹至终端）
2. **输出目录**（可拖放；不能等于或位于来源目录内）
3. **目标后缀**（如 `txt/md`，支持 `/`、`,`、空格分隔，大小写不敏感）
4. **输出扩展名**（可选，仅单个值，输入自动转小写；直接回车则保持原扩展名）
5. **处理提示词**（多行输入，含空行；单独一行输入 `[[q]]`/`[[QUIT]]` 结束，首行输入则取消；必须包含内容占位符）
6. **LLM API 地址**（OpenAI 兼容，必填；如 `http://127.0.0.1:8080`，模型名称自动探测）

参数收集完成后**回显全部参数**，确认后才执行；执行过程中逐文件输出进度，结束后输出结果汇总，最后按回车退出。

### 命令行参数（非交互）

```bash
.venv/bin/python llm-dir-handle.py \
  --src 来源目录 \
  --dst 输出目录 \
  --ext "txt,md" \
  --out-ext "md" \
  --prompt "为以下内容写一段摘要：\n[[CONTENT]]" \
  --api http://192.168.2.132:8033
```

| 参数 | 说明 |
| --- | --- |
| `--src` | 来源目录 |
| `--dst` | 输出目录 |
| `--ext` | 目标文件后缀，如 `txt/md` 或 `txt,md` |
| `--out-ext` | 输出文件扩展名（可选，仅单个值，自动转小写；留空保持原扩展名） |
| `--prompt` | 处理提示词（需包含内容占位符，如 `[[CONTENT]]`/`[[C]]`） |
| `--prompt-file` | 从文件读取处理提示词（与 `--prompt` 互斥） |
| `--api` | LLM API 地址（OpenAI 兼容，必填；`--dry` 模式下可省略） |
| `--model` | 模型名称（默认从 `/v1/models` 自动探测） |
| `--skip-existing` | 跳过输出已存在的文件 |
| `--dry` | 仅扫描统计，不调用模型、不写文件 |

> 全部参数由命令行指定时以非交互模式运行：不再回显确认、结束后不等待回车；若部分参数缺失且标准输入为非 TTY，则报错退出，不会挂起等待输入。

## 提示词说明

- 处理提示词是描述"如何处理文件内容"的自然语言，**必须包含内容占位符**，占位符会被替换为每个文件的完整内容。
- 占位符支持多种写法且**大小写不敏感**：`[[CONTENT]]`、`[[content]]`、`[[C]]`、`[[c]]` 都会被识别并替换；`[[C]]` 为简写，可能与提示词中其它 `[[...]]` 令牌冲突，建议优先使用全称。
- 推荐写法：`为以下内容写一段 200 字以内的摘要：\n[[CONTENT]]`
- 结束/取消哨兵：单独一行输入 `[[q]]`、`[[QUIT]]`（大小写不敏感）结束输入；首行输入则取消。正文中请勿使用单独成行的这些令牌。
- 占位符采用 `[[...]]` 形式而非 `{content}`，以规避提示词中出现 JSON 示例（如 `{"content": "..."}`）、单大括号或 Jinja/Handlebars 等模板语法时的误替换冲突
- 系统会附加一条指令，要求模型**只输出处理结果本身**，不添加解释或 markdown 代码围栏；即使如此，脚本仍会剥离结果首尾的代码围栏作为兜底。

## 环境变量

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `LLM_TIMEOUT` | 1800 | 单次请求超时（秒） |
| `LLM_RETRIES` | 3 | API 调用失败重试次数 |
| `LLM_TEMPERATURE` | 0.1 | 采样温度 |
| `LLM_MAX_TOKENS` | 8192 | 单次响应最大 token 数（处理类任务输出可能接近输入长度，可按需调高） |

## 说明与限制

- 输出目录会镜像来源目录的目录结构；输出文件名 = 原始文件名（去后缀）+ 输出扩展名，输出扩展名留空则保留原扩展名（本工具仍不实现自定义输出路径/名称）
- 输出目录中已存在的同名文件将被覆盖，确认阶段会提示；可用 `--skip-existing` 跳过已存在文件
- 若来源目录同时存在同名但不同后缀的文件（如 `a.txt` 与 `a.md`）且指定的输出扩展名与其中一个相同，两个文件将映射到同一输出路径，后者覆盖前者，请留意搭配选择目标后缀与输出扩展名
- 处理失败的文件保留原文件不覆盖，运行结束会列出失败清单
- 处理结果统一以 UTF-8 写入输出文件
- 文件内容整体作为一次请求发送，超大文件可能超出模型上下文窗口；必要时请先对来源文件拆分或增大 `LLM_MAX_TOKENS`
- 提示词只决定处理规则，不参与文件命名，也不会被写入输出文件
