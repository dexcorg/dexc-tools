# 大语言模型批量翻译脚本

> 当前版本：`1.0`

批量翻译指定目录中的文件，将提取出的可翻译文本通过 LLM API（OpenAI 兼容格式）翻译后输出到另一目录。支持文本、HTML、JSON、YAML、CSV 五种格式。

## 功能特性

- **交互式命令行**：来源/输出目录可拖放至控制台，参数收集后回显确认
- **5 种格式 / 8 种模式**：详见下文"文件种类"
- **批量翻译**：多段文本合并为一次 API 请求，减少调用次数
- **自动重试**：输出解析失败时自动重试并纠正提示
- **空数组兜底**：单段批次模型返回 `[]` 时视为"无需翻译"，不重试、直接保留原文
- **编码自动探测**：支持 UTF-8（含 BOM）、UTF-16、GBK、Shift-JIS 等
- **结构保真**：HTML 标签/JS 字符串、JSON/YAML 节点、CSV 单元格结构不破坏
- **智能跳过**：URL、邮箱、日期、文件路径、数字等非文本内容不翻译

## 环境要求

- Python 3.9+
- 可用的 LLM API（OpenAI 兼容格式，如本地 llama.cpp server）

## 安装

首次使用需在 `python` 目录下安装依赖（独立 venv，不污染全局环境）：

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

依赖项：`requests`、`charset-normalizer`、`ruamel.yaml`

## 使用方式

### 交互式运行

```bash
.venv/bin/python llm-dir-translate.py
```

启动后先展示工具说明横幅，再按提示依次输入：

1. **来源目录**（可拖放文件夹至终端）
2. **输出目录**（可拖放；不能等于或位于来源目录内）
3. **文件种类**（见下表，`q` 取消）
4. **目标语言**（输入序号或手动输入语言代码/名称，`q` 取消）
5. **LLM API 地址**（OpenAI 兼容，必填；如 `http://127.0.0.1:8080`，模型名称自动探测）

参数收集完成后**回显全部参数**，确认后才执行；执行过程中逐文件输出进度，结束后输出结果汇总，最后按回车退出。

### 命令行参数（非交互）

```bash
.venv/bin/python llm-dir-translate.py \
  --src 来源目录 \
  --dst 输出目录 \
  --type 4 \
  --lang 1 \
  --api http://192.168.2.132:8033
```

| 参数 | 说明 |
| --- | --- |
| `--src` | 来源目录 |
| `--dst` | 输出目录 |
| `--type` | 文件种类序号 1-8 |
| `--lang` | 目标语言序号（1=zh-CN 2=ja 3=en）或语言代码 |
| `--api` | LLM API 地址（OpenAI 兼容，必填；交互模式下省略则在提示中输入，`--dry` 模式下可省略） |
| `--model` | 模型名称（默认从 `/v1/models` 自动探测） |
| `--skip-existing` | 跳过输出已存在的文件 |
| `--dry` | 仅提取统计，不调用模型、不写文件 |

> 全部参数由命令行指定时以非交互模式运行：不再回显确认、结束后不等待回车；若部分参数缺失且标准输入为非 TTY，则报错退出，不会挂起等待输入。

## 文件种类

| 序号 | 模式 | 说明 | 扫描扩展名 |
| --- | --- | --- | --- |
| 1 | TEXT | 翻译文本全文 | `.txt` `.md` |
| 2 | HTML | 翻译可显示文本及 JS 字符串、可翻译属性 | `.html` `.htm` |
| 3 | JSON_VALUE | 翻译叶子节点值（键不变） | `.json` |
| 4 | JSON_TOTAL | 翻译全部节点（键与值） | `.json` |
| 5 | YAML_VALUE | 翻译叶子节点值（键不变） | `.yaml` `.yml` |
| 6 | YAML_TOTAL | 翻译全部节点（键与值） | `.yaml` `.yml` |
| 7 | CSV_TITLE | 仅翻译标题行 | `.csv` |
| 8 | CSV_TOTAL | 翻译全部单元格 | `.csv` |

## 环境变量

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `BATCH_ITEMS` | 8 | 每批次最多段数 |
| `BATCH_CHARS` | 400 | 每批次最多字符数 |
| `LLM_TIMEOUT` | 1800 | 单次请求超时（秒） |
| `LLM_RETRIES` | 3 | 解析失败重试次数 |
| `LLM_TEMPERATURE` | 0.1 | 采样温度 |
| `LLM_MAX_TOKENS` | 1024 | 单次响应最大 token 数 |

> 模型推理较慢时，可减小 `BATCH_ITEMS`/`BATCH_CHARS` 以降低单次响应时间；较快的模型可适当增大批量提升效率。

## 说明与限制

- 输出目录会镜像来源目录的目录结构
- 输出目录中已存在的同名文件将被覆盖，确认阶段会提示；可用 `--skip-existing` 跳过已存在文件
- 翻译失败的文件保留原文件不覆盖，运行结束会列出失败清单
- HTML 中 `<script type="application/json">` / `application/ld+json` 等内容原样保留
- YAML 使用 `ruamel.yaml` 往返，保留注释与格式
- JSON_TOTAL / YAML_TOTAL 模式下键会被翻译，若键为程序引用标识符需谨慎使用
